# 管理摘要图规范

`executive-summary.png` 用于报告顶部展示，也可用于飞书、钉钉、微信或周报传播。

推荐生成流程：

1. 从 `final-report.json` 提取整体状态、健康评分和优先问题。
2. 生成简短管理摘要文案。
3. 使用确定性渲染方式生成 PNG。
4. 如接入 GPT，可让 GPT 优化摘要文案，但必须保留确定性降级方案。

摘要图内容限制：

- 标题。
- 整体状态。
- 健康评分。
- 最多 3 条关键发现。
- 1 条建议动作。
- 巡检时间。

禁止放入：

- 长 URL。
- CSS selector。
- 堆栈信息。
- 密码、Token、Cookie、私钥。
- 大段日志。
