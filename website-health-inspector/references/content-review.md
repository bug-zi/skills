# 网站内容审查

网站内容审查用于判断页面是否可访问、内容是否完整、是否展示异常内容。

检查项：

- HTTP 状态码是否符合预期。
- 响应时间是否接近或超过阈值。
- 页面标题是否存在。
- 页面正文是否为空。
- `required_text` 中的关键文本是否出现。
- `forbidden_text` 中的异常文本是否出现。
- 页面正文长度是否低于 `min_length`。
- 是否出现常见异常文本，例如 `404`、`500`、`系统维护`、`系统繁忙`、`服务不可用`、`Internal Server Error`。

报告写法：

- 先说明对管理员的影响。
- 再说明技术证据。
- 最后给出建议动作。

示例：

```text
影响：管理员可能无法确认页面内容完整或页面已发布到正确版本。
证据：missing required_text: 管理平台
建议：核对页面内容配置、模板发布和前端资源。
```
