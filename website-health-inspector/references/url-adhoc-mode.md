# 直接 URL 临时巡检模式

当管理员只提供一个网址，而没有上传 Excel 资源清单时，使用直接 URL 模式。

默认能力：

- HTTP 状态码检查。
- DNS/连接可达性检查。
- 页面响应时间检查。
- 页面标题检查。
- 页面正文是否为空。
- 常见异常文本检查，例如 `404`、`500`、`系统维护`、`系统繁忙`。
- 可选启用受控同域页面发现。
- 生成简版 HTML 报告和管理摘要图。

缺少额外配置时，直接 URL 模式不能可靠执行：

- 管理员登录流程。
- 后台菜单点击流程。
- 主机 SSH 检查。
- systemd 微服务状态检查。
- 业务特定内容完整性检查。

直接 URL 模式会自动生成一个临时系统对象，默认优先级为 `medium`，来源类型为 `adhoc-url`。
