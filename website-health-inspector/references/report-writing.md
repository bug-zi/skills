# 管理报告写作规范

报告读者是平台管理员、运维管理员、安全管理员和管理负责人。

写作顺序：

1. 整体判断。
2. 影响系统。
3. 需要优先处理的事项。
4. 关键证据。
5. 技术详情和附录。

表达原则：

- 最终交付入口必须唯一：正式对外交付 `delivery/final-report.html`，并发送整个 `delivery/` 文件夹。外层 `final-report.html` 只作为兼容入口；历史或临时 `final-*-health-report.html` 必须由渲染器归档到 `_archived-nonfinal-html`，不得放在运行目录根部让读者误打开。
- 每次正式渲染应生成 `delivery-manifest.json` 和 `delivery-manifest.md`，用来记录正式交付包、结构化数据、Markdown 摘要、质量审计、导读图和归档草稿，方便新对话或人工交接时核对。
- HTML 报告图片必须使用相对路径并集中到 `html-assets/`，完整截图证据必须集中到 `screenshots/`；禁止把图片内嵌为 data URI，禁止引用本机绝对路径。
- 质量审计应同时输出 `quality-audit.md` 和 `quality-audit.json`：Markdown 给人读，JSON 给脚本或后续对话判断是否可交付。
- 交付摘要应支持一键复制，但复制控件只能服务于报告交接，不得引入外部依赖或把敏感信息复制进摘要。
- 先写业务影响，再写技术证据。
- 避免第一句就是 selector、堆栈、HTTP header 或命令输出。
- 建议动作要具体，避免只写“请检查”。
- 不得把“可能影响部分页面体验或需要后续排查”“请检查”“建议尽快排查”“Review needed”作为最终影响或建议。缺少证据时，明确写“影响范围尚未确认”，并补上责任角色、需要补齐的复测证据、对应服务端日志和业务预期。
- 如果评分不是 100 但评分根因表为空，不得写“未发现扣分项”或“为什么是 100 分”；应说明该分数来自覆盖缺口、未运行模块或上游汇总扣分，并指向交付清单与技术附录。
- 严重问题要简洁、直接、可行动。
- 网站健康报告必须先给“检测员判定”，再展开告警解释：公开站点是否可用、登录链路是否确认、受保护入口是否待复核、是否已经证明生产故障。
- 健康报告分析必须从整体出发，同时展示健康情况数据和不健康情况数据；健康部分只作为“健康数据基线”保留状态、数量、截图、正常页面和健康模块等证据，不做冗长分析。
- 正文分析资源应集中在不健康、待复核、自动化能力边界、自动化识别不足和风险项上，包含影响范围、证据强度、根因归并和下一步动作。
- 系统矩阵和模块证据应先展示异常/告警项，再收敛展示健康系统和健康模块；不得把健康项写成模板化长段落。
- 应提供“不健康索引”或等价的重点分析索引，明确每个需关注项的分类、责任域、影响范围和下一证据，帮助读者从整体画像跳到异常闭环。
- 优先事项不应只展示标题和日志，应至少包含证据口径、业务影响、处理路径、建议动作和下一证据。
- 面向交付的报告应提供可复制的交付摘要、风险域分布、证据包清单和复测时间线，帮助读者把报告直接转成工单、周报或复测任务。
- 带浏览器实测时，报告必须包含“性能快照”或等价章节，展示网站打开时间、平均打开时间、最慢页面、慢页面数和 TTFB；该数据是单次轻量观测，只能说明本轮巡检时的访问体验。
- 性能快照不得写成持续监控、容量评估或性能压测结论；未做多次复测、分位数统计、服务端 APM 或并发负载时，只能提示“需要持续监控或专项压测进一步确认”。
- 对“登录未确认”“受保护跳转”“401/请求中断”必须写清证据边界，区分已确认故障、高可信风险、自动化能力边界、自动化识别不足和需人工复核项。
- 如果用户或人工复测已经确认管理员账号可以正常登录，“管理员登录状态未确认”或“自动化登录态信号未确认”必须归类为自动化/MCP 操控能力边界，不能写成网站登录失败，也不能作为网站健康主要扣分项。
- 受保护页面跳转如果发生在自动化登录态未确认之后，应先解释为巡检代理可能未保持有效会话；只有在人工已确认登录态下仍异常跳转，才可升级为网站权限或路由问题。
- 推荐直接写明：“该项反映 AI/MCP 浏览器操控、登录态识别或会话保持能力不足，不是网站自身登录链路故障。”
- 单次巡检只能称为快照结论；若未做重试、多时间点检测、服务端日志或监控对比，必须明确不能判断偶发/持续。
- 对 SPA 内容完整性检查要优先采信浏览器截图和页面文本；普通 HTTP 文本过短应作为低可信提示处理。
- 结尾应给下一次检测清单，例如角色权限预期表、服务端登录日志、TLS/DNS、三次重试、关键业务路径断言和基础设施监控。

推荐表达：

```text
认证链路异常导致管理后台登录不可用，管理员无法进入后台执行配置操作。
```

检测员式推荐表达：

```text
当前判断：公开首页可访问；管理员登录链路未通过自动化确认；受保护业务入口可用性待复核；未发现已确认的生产级故障。
```

人工登录已验证正常时推荐表达：

```text
当前判断：公开首页可访问；人工登录验证正常；自动化巡检未捕获稳定登录态信号，属于巡检代理识别能力边界，不构成网站登录故障。受保护入口需在人工已确认登录态下复测。
```

不推荐表达：

```text
selector timeout: button[type=submit]
```
