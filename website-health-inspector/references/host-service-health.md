# 主机与微服务健康检查

主机与微服务健康检查用于验证管理平台背后的服务器、端口和核心服务是否可用。

第一版支持：

- `http`：请求健康检查接口，并比对预期状态码。
- `port`：测试目标主机端口是否可连接。
- `systemd`：预留远程 systemd 服务状态检查。

凭证处理：

- Excel 中只写 `auth_ref`。
- `auth_ref` 解析到环境变量或平台密钥系统。
- 报告中禁止打印真实凭证值。

当前实现说明：

- `http` 和 `port` 已可直接执行。
- `systemd` 当前采用安全降级，需要接入管理平台的受控 SSH 或堡垒机执行器后才能真正执行 `systemctl is-active`。

建议后续扩展：

- CPU、内存、磁盘使用率。
- 日志错误关键词。
- Docker 容器状态。
- Kubernetes Pod 状态。
