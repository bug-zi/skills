# 管理员浏览器流程检查

浏览器流程检查用于模拟管理员的只读操作路径，验证管理平台关键功能是否可用。

支持动作：

- `goto`
- `click`
- `fill`
- `wait_for`
- `expect_text`
- `expect_url_contains`
- `expect_selector`

典型流程：

```text
打开登录页
输入管理员测试账号
点击登录
等待跳转到后台首页
检查用户管理或审计日志页面是否可访问
```

安全规则：

- 默认 `allow_mutation=false`。
- 默认阻止删除、审批、重启、下发、封禁、结算等危险操作。
- 凭证使用 `${ENV_VAR}` 形式引用环境变量。
- 失败时保存截图、当前 URL、控制台错误和失败步骤。

报告中不能展示真实密码、Token、Cookie 或完整私钥路径。
