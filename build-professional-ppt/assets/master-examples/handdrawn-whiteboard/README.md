# Handdrawn Whiteboard Master Examples

这是一套“手绘白板风”的母版示例集。

风格关键词：

- warm white paper
- black marker outline
- blue green orange accent
- doodle-like educational vibe
- whiteboard presentation feel

这套示例的重点是：

- 展示手绘风也能做成空效果母版
- 保持留白承载，不画显性占位框
- 在统一风格下区分封面、目录、内容、结尾的角色差异

## 使用建议

- 这套更适合课程、培训、方法论、轻量科普
- 不适合作为极正式政企汇报的默认母版参照
- 历史扩展示例、错误版本和说明图统一放进 `old/`
