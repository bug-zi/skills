# Non-Handdrawn Master Examples

这是一套“非手绘风”的母版示例集。

目标：

- 作为 `assets/master-examples/` 的补充风格参照
- 展示“非手绘、正式、编辑感、学院汇报风”的空效果模板长相
- 继续坚持母版的核心原则：
  - 空效果底图
  - 强留白承载
  - 不画显性占位框
  - 不预画模块结构和流程关系

推荐风格关键词：

- editorial academic
- formal presentation background
- ivory paper
- subtle campus photography
- restrained red gold or blue gray accents
- premium but calm

这套风格锁定要求：

- 5 张基础母版必须使用同一套主色盘
- 统一暖象牙白底
- 统一低饱和写实校园建筑处理
- 统一一套主强调色，不允许一张偏红金、一张偏蓝金、一张再换别的主色
- 差异主要靠承载方向、构图、留白和气氛强弱实现

推荐文件清单：

```text
non-handdrawn-editorial/
  01-cover-empty-master.png
  02-agenda-or-section-empty-master.png
  03-content-empty-master-a.png
  04-content-empty-master-b.png
  05-ending-empty-master.png
  old/
```

使用原则：

- 先看这套图是否更接近项目气质
- 再决定是否用它做新的母版示例参照
- 如果替换旧图，把旧图移到 `old/`
- 当前目录只保留正在使用的 `5` 张标准母版
