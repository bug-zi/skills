# Master Examples Index

这个目录现在按**风格**组织母版示例，而不是把不同风格的图片平铺在根目录。

目的只有两个：

- 让 AI 先理解“什么是母版”
- 再按风格查看不同母版系统的长相

## 当前目录结构

```text
assets/master-examples/
  handdrawn-whiteboard/
  non-handdrawn-editorial/
  tech-futuristic/
```

每个风格文件夹里都应包含：

- `README.md`
- 当前风格下的 `5` 张基础母版示例
- `old/` 归档目录

## 组织原则

- 根目录只保留总说明，不堆具体示例图
- 每套示例图按风格单独成组
- 每组当前目录只保留正在使用的 `5` 张标准母版
- 每组内部再维护自己的 `old/`
- 不同风格之间不混放图片

## 先看什么

如果想看手绘感母版：
- 进入 `handdrawn-whiteboard/`

如果想看非手绘、正式、编辑感母版：
- 进入 `non-handdrawn-editorial/`

如果想看深色科技感、平台化、AI 主题母版：
- 进入 `tech-futuristic/`

## 判断标准

无论哪种风格，合格母版都必须满足：

- 是空效果底图
- 有稳定留白承载区
- 不预画具体业务结构
- 不画占位框、头像框、标题条框
- 同一套母版先统一风格，再区分页型角色
