# Tech Futuristic Master Examples

这是一套“科技未来风”的母版示例集。

风格关键词：

- midnight navy
- cyan and electric-blue light trails
- restrained holographic grid
- premium technology conference mood
- platform and AI system feel

这套示例的重点是：

- 展示深色科技风也能做成空效果母版
- 保持大面积可承载留白，不做 UI 面板堆叠
- 用统一色盘和光感区分封面、目录、内容、结尾的角色差异

## 使用建议

- 适合 AI、数字化、平台能力、产品技术、系统架构、创新发布类 deck
- 适合“科技感强，但仍然正式”的学校、企业、产品汇报
- 不适合直接拿去做极暖感、强人文、纯校园杂志式项目
- 历史失败版本或需要淘汰的图统一放进 `old/`
