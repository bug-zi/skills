# 设计元素真实性规范

这份文档用于解决“看起来像真的，但其实是编出来的元素”问题。

## 一句话规则

`先找真实元素；找不到就退回通用元素；不要伪造。`

## 哪些属于高风险造假元素

以下元素一旦做假，最容易让整套 PPT 看起来不可信：

- 学校或机构建筑
- 校门、门头、校牌、校徽、校印
- 校训、题字、石刻、雕塑
- 具体实验室、教室、场馆、展厅
- 产品界面、平台截图、设备外观
- 品牌纹样、纪念章、浮雕、专属材质
- 具体城市地标、园区、院系楼

## 元素来源优先级

优先顺序如下：

1. 用户明确提供的真实素材
2. 官方网站与官方页面截图
3. 官方公众号、视频号、宣传册、宣传片截图
4. 官方视觉识别资料、logo、校色、品牌规范
5. 项目根目录已有正式成图、历史正式稿
6. 通用元素 fallback

## 允许直接使用的真实元素

- 官方 logo
- 官网高频主色和辅助色
- 官方建筑照片
- 官方活动场景
- 官方教材、设备、产品、平台界面截图
- 官方常见纹理、底纹、海报语言

## 找不到时怎么退回

如果真实元素不足，不要硬造“像本校的建筑”或“像本品牌的 UI”，而是退回到中性、通用、不会冒充真实身份的元素。

### 学校或机构项目可用的通用元素

- 书本、讲台、教室桌椅、耳机、笔记本电脑
- 通用课堂空间、走廊、图书馆局部
- 抽象教育信息图
- 中性纸纹、石纹、金属纹、布纹
- 抽象波形、线条、节点、圆环、网格
- 通用图标：课程、评价、平台、数据、成长、协同

### 产品或平台项目可用的通用元素

- 通用设备轮廓
- 抽象界面框架
- 通用流程节点
- 图表、折线、柱状、模块卡片
- 网络连接、数据流、系统层级

### 正式汇报项目可用的通用元素

- 色带
- 标准化图示语言
- 通用纹理与边框
- 中性场景裁切
- 抽象背景与结构化图形

## 明确禁止

- 伪造某学校主楼、钟楼、教学楼
- 伪造校训题字、碑刻、印章、牌匾
- 伪造“像官网截图”的产品 UI
- 伪造机构专属雕塑、地标、院徽
- 伪造“看起来像本校”的建筑线描
- 伪造带有具体机构身份的材质浮雕

## 必须留痕

所有高风险身份元素都应记录到：

- `设计规范/element_source_log.md`

至少记录：

- 元素名称
- 元素类型
- 来源链接或来源说明
- 是否真实官方元素
- 如果不是官方元素，采用了什么通用 fallback

## 推荐日志格式

```text
# Element Source Log

| 元素 | 类型 | 来源 | 状态 | 说明 |
|---|---|---|---|---|
| 校徽 | 官方元素 | 官网首页 | 官方真实 | 可直接使用 |
| 主楼照片 | 官方元素 | 官网宣传图 | 官方真实 | 可做封面或规范板 |
| 课堂图标 | 通用元素 | 自建通用图示 | 通用 fallback | 因官方无对应图标，不冒充真实身份 |
```
