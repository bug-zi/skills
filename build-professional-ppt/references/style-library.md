# PPT 风格库

这份文档用于维护 `风格目录/`。它的目标不是堆参考图，而是把常见 PPT 风格整理成可复用的风格卡，并区分“标准风格”和“项目参考样式”。

## 使用原则

- 风格不是越多越好，而是要能复用、能区分、能落地。
- `手绘白板风` 是一种标准风格，不是唯一风格。
- 项目根目录已有 `成图/` 或 `成品目录/01-逐页成图/` 时，要优先抽象成“项目参考样式”，而不是误写成一个通用风格名。
- 风格的职责是决定页面气质、图像处理、标题语言、卡片节奏和装饰强度，不直接替代布局结构。

## 两类对象

### 1. 标准风格

指可跨项目复用的风格类型，例如：

- 手绘白板风
- 科技未来风
- 教育-信息图课堂风
- 教育-校园杂志风
- 办公-策略简报风
- 办公-培训工作坊风
- 产品-故事演示风
- 产品-界面主导风

### 2. 项目参考样式

指当前项目已有页面、成图目录、历史正式稿里抽象出的视觉样本。

它的作用是：

- 帮助理解当前项目已经形成的视觉语言
- 作为本项目继续迭代时的参考样本
- 为风格融合、微调统一提供依据

它不是：

- 一个通用标准风格名
- 一个以后所有项目都可以直接复用的风格标签

## 推荐风格目录

```text
风格目录/
  00-风格总表.md
  01-手绘白板风/
  02-科技未来风/
  03-项目参考样式-当前成图/

  05-教育-校园杂志风/

  07-办公-培训工作坊风/
  08-产品-故事演示风/
  09-产品-界面主导风/

```

每个风格目录至少包含：

- `style.md`
- `refs/`
- `moodboard/`
- `prompts.md`
- `sample-pages/`

## 01. 手绘白板风

关键词：
- 手写标题
- 白底
- 马克笔描边
- 涂鸦图标
- 彩色标签条
- 模块分栏

典型特征：
- 黑色粗手写标题是视觉核心
- 卡片边缘有手绘感，不追求机械对齐
- 颜色通常用蓝、绿、橙、红做功能分区
- 图标和小插图承担解释，不靠大段正文

适合：
- 方法论页
- 组织变革页
- 案例解释页
- 课程和培训页
- 复杂概念的轻量表达

不适合：
- 极正式政务汇报封面
- 强数据严谨表格页
- 需要大量长文字的正式公文型页面

避免误用：
- 不要把整套 deck 全部做成同样的三栏手绘页
- 不要用很多伪手写小字堆满页面

## 02. 科技未来风

关键词：
- 深海军蓝底
- 冷青蓝发光线条
- 轻网格与数据流
- 平台感
- AI 与系统能力感
- 深色但克制

典型特征：
- 统一使用深色科技底和高亮蓝青色流线
- 装饰更多压在边缘、底部、单侧，不侵占正文承载区
- 画面可以有未来感，但不能做成游戏界面或科幻电影海报
- 更强调“平台、连接、能力、系统、发布感”

适合：
- AI 项目汇报
- 数字化平台介绍
- 产品技术方案
- 系统架构与能力图
- 科技主题的发布和路演

不适合：
- 强人文、强温度的陪伴型案例页
- 纯校园杂志、纯文艺叙事页
- 超长正文、超密表格页

避免误用：
- 不要堆满发光面板、仪表盘、科幻 UI
- 不要把每页都做成同样的右下角爆发流线图
- 不要用紫蓝霓虹渐变把整套做得廉价

## 03. 项目参考样式：当前成图

身份：
- 这是当前项目的本地参考样式，不是通用风格名。

来源：
- 优先来自当前项目已有 `成图/` 或 `成品目录/01-逐页成图/`

当前浙音项目可抽象出的特征：
- 暖白纸感底
- 红金丝带或红金流线承托
- 校园真实建筑与学院环境
- 低饱和写实场景
- 音乐符号、丝带、纸纹等艺术学院识别元素
- 正式汇报感强，但不冷硬

在当前项目中适合：
- 学校汇报
- 艺术院校项目介绍
- 正式方案汇报
- 领导汇报与总结类页面

不建议直接外推为：
- 极度卡通化课程页
- 过强互联网产品发布页

避免误用：
- 不要把建筑实景复制到每一页右侧，造成审美疲劳
- 不要每一页都用同样红色结论条和同样三卡片结构

## 04. 教育-信息图课堂风

关键词：
- 清爽
- 彩色标签
- 信息图
- 学习路径
- 课堂友好

适合：
- 课程介绍
- 学习目标
- 教学流程
- 课堂活动与知识点总结

布局节奏：
- 适合多模块并列
- 适合 3-5 个知识点卡片
- 适合轻插图辅助理解

避免误用：
- 不要做成幼儿园海报感
- 不要把每个知识点都塞成一个大块长文

## 05. 教育-校园杂志风

关键词：
- 校园摄影
- 文艺留白
- 杂志排版
- 真实场景
- 学术与人文并重

适合：
- 学校介绍
- 校史与办学理念
- 招生宣讲
- 学术成果与案例展示

布局节奏：
- 大图留白更重要
- 标题和引语比卡片数量更重要
- 章节页和封面页效果更强

避免误用：
- 不要在这种风格下硬塞大量流程图和复杂功能树

## 06. 办公-策略简报风

关键词：
- 简洁
- 策略
- 咨询风
- 结构清晰
- 结论前置

适合：
- 工作汇报
- 经营复盘
- 策略说明
- 政企正式简报

布局节奏：
- 标题必须直接表达判断
- 结论条、对照结构、流程结构较常见
- 适合高密度但强层级页面

避免误用：
- 不要全部页面都是同一种咨询三段式
- 不要只剩框和字，没有识别度

## 07. 办公-培训工作坊风

关键词：
- 白板
- 工作坊
- 实操感
- 模块化
- 引导式

适合：
- 内训
- workshop
- 方法培训
- 流程演练

布局节奏：
- 适合步骤页、方法论页、角色页
- 卡片、箭头、手绘图示比较自然

避免误用：
- 不要和极正式领导汇报用同一强度的手绘笔触

## 08. 产品-故事演示风

关键词：
- 产品叙事
- 场景驱动
- 用户问题
- 价值转化
- demo 感

适合：
- 产品介绍
- 方案推介
- 新功能发布
- 场景化案例

布局节奏：
- 常用“问题 -> 方案 -> 价值”
- 常用大标题配产品界面或场景图
- 适合案例页和转化页

避免误用：
- 不要每页都满屏 UI 截图
- 不要缺少业务判断，只剩产品卖点罗列

## 09. 产品-界面主导风

关键词：
- UI 截图
- 深浅层卡片
- 功能模块
- 指标感
- 发布会式演示

适合：
- 产品界面展示
- 功能模块介绍
- 路线图
- 功能对比

布局节奏：
- 截图是主角，文字要短
- 适合单屏聚焦一个功能模块
- 更适合产品介绍，不适合重政策表达

避免误用：
- 不要把截图堆成九宫格
- 不要在没有层级梳理时堆很多 UI 小窗

## 反同质化规则

无论采用哪种风格，都要避免内容页千篇一律：

- 连续 3 页以上不要同方向左右分栏
- 连续 3 页以上不要同样数量的卡片
- 连续 2 页以上不要同一个视觉焦点位置
- 相邻两页至少在以下三项中变化一项：
  - 阅读路径
  - 图文主次
  - 结论承载方式
