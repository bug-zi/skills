# process_log.md 模板

这个模板用于记录每一轮正式修改，确保页面、大纲、讲稿、PDF 和归档文件能追溯。

## 使用方式

- 每次正式修改后追加一段，不覆盖历史记录
- 如果本轮没有改动某项，可以写“无”
- 旧文件一旦移入 `old/`，要在本轮日志里写明

## 模板

```md
## YYYY-MM-DD / v1

- 变更类型：新增页面 / 删减页面 / 修改页面
- 本次修改目标：
- 触发原因：
- 影响页面：
- 页面变更摘要：
- 同步更新文件：
- 新增文件：
- 移入 `old/` 的旧文件：
- 一致性检查：
  页面 vs 大纲：
  页面 vs 讲稿：
  页面 vs PDF：
- 风险或待确认项：
```

## 示例

```md
## 2026-04-23 / v3

- 本次修改目标：重做第 09 页整体架构页，并同步更新讲稿
- 触发原因：架构页结构层级不清，和最新大纲不一致
- 影响页面：09
- 页面变更摘要：重新生成无字结构底板，调整标题与标签层级，补充治理层说明
- 同步更新文件：
  - PPT大纲/PPT大纲-逐页内容.md
  - 成品目录/03-讲稿/speech_script.md
  - 成品目录/03-讲稿/slide_speech_map.md
- 新增文件：
  - 素材目录/03-逐页素材/09-整体架构/step-03-main-visual.png
- 移入 `old/` 的旧文件：
  - 素材目录/03-逐页素材/09-整体架构/old/step-03-main-visual-2026-04-23-v2.png
  - 成品目录/01-逐页成图/old/slide-09-2026-04-23-v2.png
- 一致性检查：
  页面 vs 大纲：已同步
  页面 vs 讲稿：已同步
  页面 vs PDF：待重导出
- 风险或待确认项：第 10 页运行机制页可能也需要同步微调
```
