# PDF 导出 Playbook

这一步在最终逐页成图已经稳定之后执行。目标是把成品目录里的逐页成图导出为一个正式 PDF。

## 输入来源

默认只使用这里的文件：

- `成品目录/01-逐页成图/`

不要使用：

- `素材目录/`
- 中间稿
- 候选图
- 未定稿版本

## 输出位置

默认输出到：

- `成品目录/04-PDF导出/`

默认文件名：

- `<项目名>-汇报.pdf`

如果用户明确要求，可以补充：

- `<项目名>-屏幕版.pdf`
- `<项目名>-打印版.pdf`
- `<项目名>-汇总版.pdf`

## 推荐导出方式

优先使用本 skill 自带脚本：

```bash
python3 scripts/export_slide_images_to_pdf.py \
  --input-dir "成品目录/01-逐页成图" \
  --output "成品目录/04-PDF导出/项目名-汇报.pdf"
```

默认脚本会：

- 按文件名自然排序
- 合并常见图片格式
- 自动生成一个合并 PDF

说明：

- 这里的 Python 只用于把已经完成的逐页成图合成为 PDF
- 类似 `from pathlib import Path` 这样的写法只是处理文件路径，不是在画 PPT
- 不要把 PDF 导出脚本扩展成页面绘制或页面排版脚本

## 导出规则

- 页序必须和最终页序一致
- 优先保持原始横版比例，不要强行改成 A4 竖版
- 不要自动裁切内容
- 不要把低清中间稿混入 PDF
- 如果有封面、章节页、尾页，都必须完整纳入

## 导出前检查

至少检查四件事：

1. 页数是否完整
2. 页序是否正确
3. 首尾页是否都在
4. 画面是否出现裁切、拉伸、压缩失真

## 交付建议

推荐做法：

- `成品目录/01-逐页成图/` 保留逐页图片
- `成品目录/04-PDF导出/` 保留正式 PDF
- `成品目录/05-汇总交付/` 放最终要交付给用户的整套文件

## 常见错误

- 页面还没定稿就先导出 PDF
- PDF 用的是中间稿，不是最终图
- 页序和大纲不一致
- 横版页面被错误压到竖版比例里
