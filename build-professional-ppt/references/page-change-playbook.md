# 页面增删改 Playbook

这份文档用于规范三类高频动作：

1. 新增页面
2. 删减页面
3. 修改页面

核心顺序始终不变：

1. 先改大纲
2. 再改内容
3. 再判断是否要改设计
4. 再重走页面施工
5. 再做审查与微调
6. 最后同步讲稿和 PDF

## 一、如何新增页面

### 适用场景

- 原有页数不够，需要补一页论证、案例、结构或转场
- 汇报逻辑有断层
- 用户明确要求增加页面

### 动作顺序

1. 确认新增目的和插入位置
2. 先更新 `PPT大纲*.md`：
   - 页码
   - 标题
   - 主判断
   - 信息单元
   - 素材需求
3. 再判断是否需要更新 `design.md`
4. 如项目采用固定模版或风格，还要同步：
   - `模版目录/00-模版总表.md`
   - `风格目录/00-风格总表.md`
5. 建立新页素材目录和 `old/`
6. 再按单页施工流程生成：
   - `5A` 页面施工卡
   - `5B` 空背景图
   - `5C` 页面结构框定
   - `5D` 图文一体整页成图
   - `5E` 复杂示意图拆分与拼装
   - `5F` 局部微调与统一
   - `5G` 单页复核
   - `5H` 资产归档
7. 同步更新讲稿：
   - `slide_speech_map.md`
   - `speech_script.md`
8. 重导 PDF
9. 更新 `process_log.md`

## 二、如何删减页面

### 适用场景

- 页面重复
- 信息密度过低
- 内容可并入前后页
- 用户要求压缩页数

### 动作顺序

1. 先确认删页原因
2. 先判断删除后前后页如何衔接
3. 先把旧文件归档到最近的 `old/`
4. 再更新 `PPT大纲*.md`
5. 同步更新：
   - `slide_speech_map.md`
   - `speech_script.md`
   - `review_report.md`
6. 如页序变化影响模版编排，也同步更新 `模版目录`
7. 重导总览拼图和 PDF
8. 更新 `process_log.md`

## 三、如何修改页面

### 先判断修改类型

#### 1. 轻改

适用于：

- 改标题
- 改一两段短文字
- 换一张图
- 调整局部平衡

通常动作：

1. 判断主判断是否变化
2. 如有变化，先改 `PPT大纲*.md`
3. 归档旧文件到 `old/`
4. 从 `5D`、`5F` 或 `5G` 回退
5. 同步讲稿和 PDF

#### 2. 中改

适用于：

- 信息单元变化
- 版式变化
- 图文关系重排
- 页面节奏需要调整

通常动作：

1. 先改 `PPT大纲*.md`
2. 判断是否要改 `design.md`
3. 判断是否要调整风格或模版映射
4. 归档旧文件
5. 从 `5A`、`5C` 或 `5D` 回退
6. 审查后再同步讲稿和 PDF

#### 3. 重改

适用于：

- 页面定位变化
- 从普通页改成架构页或流程页
- 需要改成复杂示意图分件拼装
- 原页面风格与整套不一致

通常动作：

1. 先改 `PPT大纲*.md`
2. 必要时更新 `design.md`
3. 必要时同步 `风格目录` 或 `模版目录`
4. 归档旧文件
5. 从 `5A` 重新走完整单页流程
6. 重新审查，再同步讲稿和 PDF

## 四、动作顺序总结

无论是新增、删减还是修改页面，都先按这个顺序判断：

1. 改不改大纲
2. 改不改内容单元
3. 改不改设计规范
4. 改不改风格或模版映射
5. 重不重做页面
6. 同不同步讲稿
7. 要不要重导 PDF

## 五、常见错误

- 直接改页面，不改大纲
- 继续沿用旧的无字效果板流程
- 复杂页没有分区，硬塞一整页
- 改了页面标题，但讲稿还是旧标题
- 增加了一页，但 PDF 页序没更新
- 修改页面前没有把旧文件移入 `old/`
