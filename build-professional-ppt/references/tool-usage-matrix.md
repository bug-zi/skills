# 工具使用矩阵

这份文档规定 build-professional-ppt 每一步应该使用什么工具。最重要的执行心智只有一句话：

`视觉主工具永远是 imagegen，视觉动作只有生图或微调图。`

其它工具都只是辅助：

- `web` 用来找资料
- 提示词模板库用来找模板
- 文档编辑用来写规范、大纲、讲稿
- 命令行用来建目录、归档、导出、校验

## 总原则

重要事说三遍：

- `视觉主工具只有 imagegen。视觉主工具只有 imagegen。视觉主工具只有 imagegen。`
- `不要 builder，不要代码排版，不要 build_deck.mjs。不要 builder，不要代码排版，不要 build_deck.mjs。不要 builder，不要代码排版，不要 build_deck.mjs。`
- `先分析，再调研，再确认，再母版，再正式成图。先分析，再调研，再确认，再母版，再正式成图。先分析，再调研，再确认，再母版，再正式成图。`
- `母版确认后，先整理逐页文字与素材，再直接正式成图。母版确认后，先整理逐页文字与素材，再直接正式成图。母版确认后，先整理逐页文字与素材，再直接正式成图。`

- `imagegen` 是唯一允许用于生成母版、视觉素材、页面框定、子图、整页成图和局部微调的图像生产工具。
- 只要任务是“让画面发生变化”，主工具就必须回到 `imagegen`。
- 不是每个阶段都必须生图。`design.md`、大纲、逐页文字与素材整理、讲稿、日志这些文档阶段，默认不调用 `imagegen`。
- 母版确认和大纲确认通过后，默认动作是整理逐页文字与素材，然后直接在已确认母版上生成正式页，不再默认生成章节分镜、缩略图拼板或参考视觉页。
- 视觉执行默认都走这条链路：
  1. 找场景提示词模板
  2. 套入当前页需求
  3. 决定是生图还是微调图
  4. 调用 `imagegen`
  5. 复核并归档
- `web` 只用于调研官方资料、品牌资料、行业参考和外部风格样本，不能用于生成页面。
- 本地命令行只用于读文件、建目录、移动旧文件到 `old/`、校验 skill、导出 PDF、整理文件名，不能画页面。
- 文档编辑只用于写 `design.md`、大纲、讲稿、过程记录、审查报告，不能替代 imagegen 成图。
- PDF 脚本只用于把最终逐页成图合成为 PDF，不能扩展为页面绘制或排版脚本。
- 视频脚本只用于把最终逐页成图和最终讲稿转换为语音、字幕和 MP4，不能扩展为页面绘制、贴字或排版脚本。
- 当用户显式启用 `build-professional-ppt` 时，通用 `PowerPoint` skill、JS builder、`build_deck.mjs`、artifact-tool 预览渲染链路都不能接管页面生产。
- 开工前先做一次冲突检查。如果发现通用 `PowerPoint` skill 也可能被同时触发，先提醒用户关闭或不要继续启用它，只保留 `build-professional-ppt`。
- 冲突提醒优先使用固定文案：
  - `检测到当前项目可能同时触发了通用 PowerPoint skill。为了避免切到代码 builder 路线，请先只保留 build-professional-ppt 再继续。如果你要的是可编辑 .pptx 且接受代码排版，请明确改用 PowerPoint skill。`
- 发出这条提醒后，先停在当前阶段，等用户确认路线，不要继续生成页面或导出。
- 沿用旧版成图、旧 deck、旧 pdf/pptx 是一个需要显式授权的分支；如果用户没明确要求沿用，就把旧项目成果当作参考样式、内容来源和可复用素材，而不是直接当成新项目首版。
- 禁止用 PowerPoint、Keynote、Figma、HTML、Canvas、SVG、JS、Python、`@oai/artifact-tool` 从零画母版或正式页，除非用户明确改需求为“可编辑 PPT/程序化生成 PPT”，那就不再按本 skill 执行。

冲突信号包括：

- 用户同时要求 `PowerPoint` / 可编辑 `.pptx` / builder
- 当前对话中出现 `build_deck.mjs`
- 当前对话中出现 artifact-tool、preview render、output.pptx 抽查等 builder 话术
- 当前动作开始转向坐标排版、脚本构建、preview 渲染链路

## 禁止工具清单

下列工具不能参与页面视觉生产：

- `python-pptx`
- Python 绘图库
- `python3 - <<'PY'` 内联绘图脚本
- JavaScript / TypeScript 坐标排版脚本
- `@oai/artifact-tool`
- HTML / CSS 页面合成
- Canvas / SVG 绘制
- 浏览器截图链路
- `build_deck.mjs` 或任何 JS builder 文件
- codex-primary-runtime/slides 的 builder 排版路线
- PowerPoint / Keynote 手工排版成正式页

允许它们做的事：

- 校验
- 导出
- 归档
- 重命名
- 生成索引
- 合成 PDF
- 查看文件结构

## 阶段工具矩阵

说明：

- 表里的“主工具”是该阶段的主工作方式。
- 只要该阶段涉及视觉生产，主工具都应该理解为 `imagegen`。
- 其它工具只是辅助准备或辅助收尾。

| 阶段 | 主工具 | 辅助工具 | 禁止使用 | 主要产物 |
|---|---|---|---|---|
| -1 分析项目与现有资料 | 本地文件读取、文档编辑 | `rg`、文件列表、旧资产查看 | 一上来就生图 | `project_analysis.md` 或分析章节 |
| 0 调研查资料 | `web`、本地文件读取、`imagegen` | 命令行整理截图和文件 | 代码画页面 | `research_brief.md`、调研风格板 |
| 1 建立上下文与资源库 | 本地文件读取、命令行建目录、文档编辑 | `rg`、`find`、`mkdir`、`mv` | 用脚本生成页面 | 六类目录、`process_log.md` |
| 2 生成母版组 | `imagegen` | `references/master-examples.md`、`references/prompt-template-library.md` | PPT/JS/Python/HTML 画母版 | 多张空母版图 |
| 3 写 `design.md` | 文档编辑 | 本地文件读取 | 代码排版页面 | `design.md` |
| 4 梳理大纲内容 | 文档编辑 | 本地文件读取 | 直接跳到代码生成页 | `narrative_plan.md`、`PPT大纲*.md` |
| 4.6 逐页文字与素材整理 | 文档编辑、本地文件读取 | 逐页素材目录 | 章节分镜拼板、参考视觉页 | 每页 `内容与素材清单.md` |
| 5 逐页成图 | `imagegen` | 文档编辑记录施工卡、命令行归档文件 | 一切代码驱动排版 | 每页过程素材、最终整页图 |
| 6 审查与微调 | 视觉查看、文档编辑 | 命令行查看文件、归档旧版、按需 `imagegen` | 脚本批量重排页面 | `review_report.md`、按需微调素材 |
| 7 讲稿生成 | 文档编辑 | 本地文件读取 | 脱离成图另写讲稿 | `speech_script.md`、`speaker_notes.md` |
| 8 交付导出 | PDF 导出脚本、演示文稿封装能力、文档导出能力、视频导出脚本 | 命令行校验页序、文件管理、`ffmpeg`、`ffprobe`、MiniMax TTS | 在导出阶段重画页面 | `.pdf`、`.pptx`、`.docx`、`.mp4`、`.srt` |
| 9 校验交付 | 命令行、文档检查 | 文件列表、导出文件抽查 | 修改页面而不留痕 | 交付清单、最终归档 |

## 逐页施工工具矩阵

一句话理解：

- `5B-5F` 的主工具都只有 `imagegen`
- `5A` 是写清需求
- `5G-5H` 是复核和归档

| 步骤 | 主工具 | 辅助工具 | 说明 |
|---|---|---|---|
| 5A 页面施工卡 | 文档编辑 | `references/layout-patterns.md`、`references/prompt-template-library.md` | 写清页型、母版、内容、路径 |
| 5B 选用或派生空母版 | `imagegen` | 母版组、母版示例 | 只能生成空模板或选择已有空模板 |
| 5C 页面结构框定 | `imagegen` | 文档记录分区方案 | 仅复杂页进入；普通页跳过 |
| 5D 图文一体整页成图 | `imagegen` | 场景提示词模板 | 直接生成带真实文字和图像的整页图 |
| 5E 复杂分件 | `imagegen` | 分区方案 | 复杂页按子图生成，不用代码画图 |
| 5F 局部微调 | `imagegen` | 旧版归档 | 局部重绘、补位、统一风格 |
| 5G 单页复核 | 视觉查看、文档检查 | `design.md`、大纲 | 判断是否回退 |
| 5H 资产归档 | 命令行移动文件、文档编辑 | `process_log.md` | 只做文件管理，不做页面生产 |

## 工具选择判断

如果任务是“生成或改变视觉画面”：
- 必须用 `imagegen`
- 然后只判断这是：
  - `生图`
  - `微调图`

如果任务是“查资料、看官网、找官方风格”：
- 用 `web`

如果任务是“写规范、大纲、讲稿、日志、审查报告”：
- 用文档编辑

如果任务是“移动文件、建目录、旧版归档、校验 skill”：
- 用命令行

如果任务是“导出最终交付文件”：
- `PDF`：用 PDF 导出脚本
- `PPT`：用演示文稿封装能力，把最终页图装成一图一页的 `.pptx`
- `Word`：用文档导出能力，把最终讲稿或汇报资料导出成 `.docx`
- `Video`：用 MiniMax TTS + `ffmpeg` 把最终页图和最终讲稿导出成旁白视频，可选 `srt`、软字幕或硬字幕

如果任务是“按坐标画卡片、写文字、画母版、画正式页”：
- 停止，这不是本 skill 的工作方式

## 违规信号

出现以下行为，说明工具用错了：

- 页面长什么样由脚本坐标决定
- 母版由 JS/Python 函数画出来
- 正式页由 HTML/CSS 再截图得到
- 文字由浏览器或 PPT 插件后贴上去
- `imagegen` 只被用来做背景，真正排版靠代码完成
- PDF 导出脚本开始承担绘图、排版、贴字职责

## 正确链路

```text
资料调研：web + 本地文件读取
找模板：prompt-template-library
视觉生产：imagegen 生图或微调图
规范、大纲、文字与素材整理：文档编辑
过程管理：命令行 + 文档编辑
讲稿：文档编辑
PDF：最终图片合成脚本
PPT：最终页图封装为 `.pptx`
Word：最终 markdown 文档导出为 `.docx`
Video：最终页图 + 最终讲稿 -> TTS 语音 -> 字幕 -> MP4
```
