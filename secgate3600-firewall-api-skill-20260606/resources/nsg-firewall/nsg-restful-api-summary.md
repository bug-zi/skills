## URL Model

The guide documents these base paths:

```text
{http|https}://{IP}:{port}/v1.0/login
{http|https}://{IP}:{port}/v1.0/out
{http|https}://{IP}:{port}/v1.0/rest/
```

## Auth Model

The extracted text states that requests use cookies to store the REST API `SESSIONID` and authenticated `TOKEN`. This matches local testing on SecGate 3600 where token-as-cookie changed `/v1.0/rest` behavior.
